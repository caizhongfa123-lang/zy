打开 `index.html` 就能玩，不用安装、不用配置。

---

## 怎么打开

1. 下载本项目，双击 `index.html`（或者把它拖进浏览器）
2. 首次进入先选一个「作战账号」（主账号 + 最多 6 个练习账号，各自独立存档）
3. 从「训练场」答题赚哈夫币 → 去「军械库」买枪和防弹衣 → 到「行动」选地图下战场

不联网也能玩（进度存在本机浏览器里）；联网时会自动同步到云端数据表。

## 特色玩法

- **答题赚军费**：答对题拿哈夫币，答错自动进错题本，错题可以反复重做
- **撤离机制**：把物资背到绿色撤离点站满 3 秒才算带走；阵亡会丢掉带进图的枪和甲
- **干员技能**：红狼加速、威龙加伤害、牧羊人减伤、蜂医回血、露娜提升开箱品质等
- **钓鱼**：长弓溪谷找老渔夫拿鱼竿，之后在任何水边按 F 抛竿，钓到的鱼在补给站卖钱
- **攻击艇**：长弓溪谷溪边可登艇，WASD 驾驶、舰炮范围伤害
- **刷卡房间**：金色描边的上锁房间，没有门卡就在门口答对 5 题应急解锁
- **账号时段规则**：主账号是家长账号（可设 4 位密码），打行动不限时；练习账号只在周末和法定节假日能打行动，每天最多 1 小时

## 关于版本号

版本号只有**一处**定义：`index.html` 里的 `APP_VER`（旁边还有 `APP_DATE` 记更新日期）。

改这一行，以下三处显示会自动跟着变：

1. 顶栏品牌小字：`OPERATION MATH · V1.0.0`
2. 作战室首页底部版本条：`数学作战台 v1.0.0 · 上次更新：2026-10-11`
3. 浏览器标签标题：`数学作战台 v1.0.0 · 三角洲行动学习基地`

发布新版本时，同时打一个同名 git 标签（例如 `v1.0.1`），本页顶部的版本徽章会自动更新。
