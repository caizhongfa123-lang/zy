干员档案
干员皮肤
点干员头像看立绘；招募后点「出战」生效加成。每位干员都带一个「行动技能」：出战后进「行动 · 枪战」会自动生效（加伤害、加移速、回血、减伤等）。每位干员还带两个「主动技能」——进图后按 G / C 释放（手机点右下角两个技能按钮），放完要等冷却。每个人物都是画出来的——立绘下面那张「战场形象」就是他在枪战里跑动的样子（从头顶往下看）：8 位干员的体型、头盔、面罩、背后装备各不相同，谁是谁一眼能认出来。皮肤买一次全队通用，换的是整套配色，选哪套小人就穿哪套上场。
行动准备
七张地图各有各的地貌，卡片上那张缩略图就是进图后脚下的样子：零号大坝是混凝土坝板（板缝 + 四角螺栓 + 排水孔），长弓溪谷是林地草皮（草簇 + 泥土斑），巴克什是城区柏油街面（人行道砖 + 黄色路标线），潮汐监狱是石板院子（十字缝 + 排水格栅），航天基地是发射场跑道（混凝土板 + 白色导引虚线 + 黄黑警示带），AZ3 核电站是反应堆厂区水泥板（板缝 + 螺栓，地上还铺着几圈发绿光的核辐射区），大战场是泥地车辙（弹坑 + 积水）。墙体材质、路边摆件（油桶 / 树丛 / 街灯 / 探照灯 / 雷达 / 沙袋）、角落大件（集装箱 / 汽车 / 燃料罐 / 哨塔 / 弹药库）也都按地图各换一套，右上角小地图同样按主题上色。
军火库 · 武器采购
9 把枪长得都不一样：卡片上那张侧视图就是它进图握在你手里的样子——M9 手枪最短、MP5 带前竖握把和长弹匣、AKM 是下斜木托配弯月弹匣、M4A1 有长提把导轨、M870 中间那截是撸一下的泵动护木、SV-98 和 AWM 带大倍镜和两脚架（AWM 最长）、AA-12 挂着鼓形弹匣、M134 是三根枪管并排转。所有枪都按同一比例画，所以短枪显短、长枪显长；卡片用的是你当前装的那款枪皮，换了涂装整排预览跟着变。

秒才算成功带走；阵亡或超时，这一趟的物资全部丢失。长弓溪谷的河道与攻击艇：「长弓溪谷」地图中间横着一条蓝色的「长弓溪」，涉水移动会变慢（大约七成速度），水面上有三座褐色木桥，走桥上不减速；溪边停着一艘攻击艇——走到艇旁按 E（手机端点右下角「上艇」）登艇，WASD 驾驶，艇只能在溪水里开、上不了岸；按住左键 / 空格发射舰炮，炮弹是范围伤害，一发就能轰掉一小片敌人，弹舱 6 发、打空按 提竿，手慢了鱼就跑了。抛竿的时候别走动、别开枪，不然会惊跑鱼。钓上来的鱼会直接放进补给站的「渔获鱼篓」，不会因为阵亡丢失，去补给站点「一键卖光鱼篓」就能换成哈夫币。鱼的档次跟着地图难度走：零号大坝多是鲫鱼，航天基地容易上大青鱼、金鳞锦鲤（一条值 620）。每次行动最多钓 6 条。刷卡房间：每张地图有金色描边的上锁房间（零号大坝 1 间、长弓溪谷 2 间、巴克什 3 间、潮汐监狱 3 间、航天基地
